# Knowledge base monitoring test page

A web page we control, so that knowledge base page monitoring can be tested without
waiting for a county to edit their own website.

`index.html` is published at <https://appraised.github.io/kb-monitoring-test-page/> and is
watched by the monitoring feature in **staging only**. Editing the text in `index.html` and
pushing produces a real detected change on the next check, which is the only way to
exercise the page-change-to-article-rewrite path on demand.

Why this exists: in twelve days of watching 36 real pages across two clients, not one
meaningful change occurred. Government sites change slowly, so waiting for one is not a
test plan.

## The content is invented

There is no Example County. The exemption rules, deadlines and office hours on the page
are made up. Nothing here comes from any client. Do not copy it anywhere or use it as an
example of how a real assessor's office works.
